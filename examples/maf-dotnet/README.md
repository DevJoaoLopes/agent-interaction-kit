# Export Microsoft Agent Framework tools from .NET

A Microsoft Agent Framework (MAF) agent in .NET describes each tool as an `AIFunctionDeclaration`
(`Microsoft.Extensions.AI`): `Name`, `Description`, `JsonSchema` for the arguments and
`ReturnJsonSchema` for the result (both present in `Microsoft.Extensions.AI.Abstractions` 11.0.1). This example serializes those
fields to the generic tools-json format, so `aik manifest` and `aik check` can use the real schemas of your
tools instead of a hand-written manifest. There is no NuGet package to install: copy
[`ToolsJsonExporter.cs`](AikToolsExport/ToolsJsonExporter.cs) into your agent project.

```text
AikToolsExport/        console app: ToolsJsonExporter.cs (the exporter) + SampleTools.cs (AIFunctionFactory.Create examples)
AikToolsExport.Tests/  xUnit tests: the exporter output must equal fixtures/tools.json
fixtures/tools.json    generated by the exporter from SampleTools
fixtures/consumer.json a consumer that matches it, used by the core tests
```

## Use it

1. Pass your agent's tools (the `AITool` list you give to the agent or to `ChatOptions.Tools`) to the exporter:

   ```csharp
   File.WriteAllText("tools.json", ToolsJsonExporter.Export(tools));
   ```

   An invocable `AIFunction` becomes a `backend` tool. A declaration-only tool (an `AIFunctionDeclaration`, for
   example `AIFunctionFactory.Create(...).AsDeclarationOnly()`) becomes a `frontend` tool, because the AG-UI client
   runs it. Tools that are not functions (for example `HostedWebSearchTool`) have no schema, so the exporter throws
   an `ArgumentException` that names the tool instead of exporting a wrong contract.

2. Generate the provider manifest and check it against the frontend's expectations:

   ```bash
   npx --no-install aik manifest --from tools-json tools.json \
     --producer-name my-agent --producer-version 1.0.0 --build-id "$GIT_SHA" \
     -o aik.provider.json
   npx --no-install aik check --provider aik.provider.json --consumer aik.consumer.json --strict
   ```

## Run the example and its tests

Needs the .NET SDK 10 (tested with 10.0.404) and the packages restored from NuGet
(`Microsoft.Extensions.AI.Abstractions` 11.0.1, xUnit 2.9.3).

```bash
cd examples/maf-dotnet
dotnet test AikToolsExport.Tests                              # exporter output equals fixtures/tools.json
dotnet run --project AikToolsExport -- fixtures/tools.json    # regenerate the fixture
```

The `fixtures/tools.json` file comes from a real `AIFunctionFactory.Create`: it keeps the schema that .NET
produces, including `enum` values, `"type": ["integer", "null"]` for nullable parameters and `"default": null`. The
core test `packages/core/tests/e2e/maf-dotnet-fixture.test.ts` runs `aik manifest` and `aik check --strict` on it.

## Not covered

- MAF for Python (`agent-framework`): a Python exporter is not part of this example.
- The exporter reads declarations; it does not call a model or run an agent.
- The .NET tests are not part of the repository's CI workflow yet.
